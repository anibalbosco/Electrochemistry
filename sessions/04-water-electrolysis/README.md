# Session 4 — Water Electrolysis and Gas Collection

**Hook:** Tap water barely splits — add electrolyte, measure current, prove 2:1 stoichiometry, then pop an H₂ balloon.

## Learning outcomes

- Explain why **tap water alone** electrolyzes poorly (few ions)
- Show that **Na₂SO₄** electrolyte increases current and reaction rate
- Measure **current** and estimate **H₂/O₂ production rate** with Faraday’s law
- Relate applied **voltage** to the ~1.23 V minimum for water splitting
- Collect gases in a **U-tube** and confirm **~2:1 H₂:O₂** stoichiometry
- Identify H₂ with an instructor-led **balloon pop** demo
- **Start** electrolytic rust-removal cells for Session 5

## Key reactions

```
Overall: 2H₂O(l) → 2H₂(g) + O₂(g)

Cathode (−): 2H₂O + 2e⁻ → H₂ + 2OH⁻
Anode (+):   2H₂O → O₂ + 4H⁺ + 4e⁻   (acidic media)
         or 4OH⁻ → O₂ + 2H₂O + 4e⁻   (basic media)

Rate (Faraday): ṅ(H₂) = I / (2F),  ṅ(O₂) = I / (4F)
```
